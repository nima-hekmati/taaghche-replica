# سامانه کتابخوان طاقچه (Taaghche Web App)
### تمرین اول درس برنامه‌سازی وب — دانشکده مهندسی کامپیوتر دانشگاه صنعتی شریف
**استاد درس:** جناب آقای علی ابریشمی  
**نیم‌سال تحصیلی:** پاییز ۱۴۰۴/۱۴۰۵  
**طراحان تمرین:** مهبد خالقی، محمدحسین شفاعت، مانی ابراهیمی  

---

## ۱. معرفی و اهداف پروژه
این پروژه یک وب‌اپلیکیشن تعاملی، مدرن و کاملاً راست‌به‌چپ (RTL) به زبان فارسی است که با الهام از ساختار بصری و تجربه‌ی کاربری وب‌سایت **طاقچه** پیاده‌سازی شده است.  
مطابق با الزامات تمرین، این سامانه **کاملاً مستقل از هرگونه کتابخانه، فریم‌ورک خارجی، قالب آماده یا CDN** بوده و منحصراً بر پایه استاندارد‌های بومی مرورگر (**Vanilla HTML5, Pure CSS3, Vanilla JavaScript**) توسعه یافته است.

---

## ۲. مسیر شروع و نحوه اجرای پروژه
پروژه برای اجرا به هیچ‌گونه نصب وابستگی، مدیر بسته‌ای نظیر `npm` یا راه‌اندازی پایگاه‌داده نیاز **ندارد**.

### روش ۱: اجرای مستقیم (بدون وب‌سرور)
کافی است فایل `index.html` در ریشه پروژه را در مرورگر وب دلخواه خود باز کنید (با دو بار کلیک یا کشیدن و رها کردن فایل در مرورگر).

```bash
# باز کردن مستقیم در مرورگر در محیط لینوکس
google-chrome index.html
# یا در مک / ویندوز
open index.html
start index.html
```

### روش ۲: اجرای از طریق سرور محلی سبک
در صورت تمایل به اجرای تحت سرور محلی پروتکل `http://`:

```bash
python3 -m http.server 8000
```
سپس در مرورگر نشانی زیر را باز فرمایید:
```
http://localhost:8000
```

## ۴. روش پاک کردن وضعیت ذخیره‌شده (Reset State)
تمام وضعیت‌های برنامه (کتاب‌های دریافت‌شده، کتاب‌های مورد علاقه، اطلاعات کاربر و تنظیمات مطالعه) به صورت ایمن در `localStorage` مرورگر نگهداری می‌شوند. برای بازنشانی کامل وضعیت به حالت اولیه دو روش وجود دارد:

1. **از طریق رابط کاربری:** در پاورقی سایت (Footer)، در بخش «راهنما و خدمات»، روی گزینه **«پاک کردن وضعیت مرورگر (Reset)»** کلیک کنید. با این کار تمام داده‌ها پاک شده و صفحه به صورت خودکار تازه‌سازی می‌شود.
2. **از طریق ابزار توسعه‌دهنده مرورگر (Console):** کلید `F12` را فشرده، وارد تب `Console` شوید و دستور زیر را اجرا فرمایید:
```javascript
localStorage.clear();
location.reload();
```

## ۷. امنیت و استانداردهای توسعه
- **امنیت داده‌ها:** جهت جلوگیری از آسیب‌پذیری‌های تزریق اسکریپت (XSS)، ورودی‌های متنی کاربر منحصراً با `textContent` یا ایجاد المان‌های ایمن درج شده‌اند.
- **انعطاف‌پذیری:** خطاها و ورودی‌های خراب در `localStorage` توسط ساختار `try / catch` احاطه شده و به هیچ وجه مانع اجرای برنامه نمی‌شوند.
- **دسترس‌پذیری (A11y):** تمام المان‌های ورودی دارای برچسب (`<label>`) هستند، تصاویر دارای ویژگی `alt` توصیفی می‌باشند و با فشردن کلید `Escape` پنجره‌های فعال بسته می‌شوند.
